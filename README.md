# Ziyan Khan - Portfolio Website 🚀

Welcome to the repository of my personal portfolio website! 
This is a modern, premium, and fully responsive single-page portfolio designed to showcase my skills, internships, certifications, and projects as an AI & ML Engineering student.

## 🎨 Features
- **Sleek Dark Theme:** A visually stunning deep blue mesh gradient background with glassmorphism UI.
- **Fully Responsive:** Looks perfect on both desktop and mobile devices.
- **Categorized Skills:** Clear breakdown of Frontend, Backend, Programming, and AI/ML skills.
- **Interactive UI:** Smooth scrolling, hover animations, and floating cards.
- **Dedicated Sections:** For Internships, Top Certifications, Projects, and Contact details.

## 🛠️ Built With
- **HTML5** for structure
- **CSS3** (Vanilla CSS) for styling, glassmorphism, and animations
- **JavaScript (Vanilla)** for interactivity and smooth scrolling
- **FontAwesome** for icons
- **Google Fonts** (Outfit) for modern typography

   ```bash

   ```
2. Navigate to the project directory:
   ```bash
   cd portfoliyo
   ```
3. Open `index.html` in your browser or use an extension like **Live Server** in VS Code.
